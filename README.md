# ❤️ Heart Score

Heart Score is a simple web application designed to predict the risk of heart disease based on user input. This project uses a machine learning model served through a Flask backend.

## 🚀 Getting Started

### Prerequisites

Make sure you have the following installed:

- Python 3.7+
- pip (Python package installer)

### 🛠️ Installation

1. Clone this repository:
   ```bash
   git clone https://github.com/your-username/heart-score.git
   cd heart-score
Start the Flask app by running:
python app.py
